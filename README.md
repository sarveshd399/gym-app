# Gym App (Next.js + Supabase)
1. Create a Supabase project, run `schema.sql` in the SQL Editor.
2. `cp .env.example .env.local` and fill in the keys (Project Settings -> API).
3. `npm install && npm run dev`
4. Register the trainer on /login, then run the admin `update` query at the bottom of schema.sql.
